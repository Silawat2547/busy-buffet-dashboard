# Busy Buffet — Data Analyst Test

แดชบอร์ดภาษาไทยประกอบด้วยภาพรวม, Task 1, Task 2, Task 3 และข้อมูล/วิธีวิเคราะห์ พร้อมไฟล์ Excel ประกอบ 4 ไฟล์

## เปิดบนเครื่อง

ใช้ Python 3.12 แล้วติดตั้งและเปิดด้วย:

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## เผยแพร่บน Streamlit Community Cloud

1. เข้าสู่ระบบ GitHub และสร้าง repository สำหรับงานนี้
2. ใส่ไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ลงใน repository โดยให้ app.py และ requirements.txt อยู่ระดับบนสุด เก็บ data/, downloads/ และ .streamlit/ ไว้ด้วย ไม่ต้องใส่ไฟล์ ZIP
3. เข้าสู่ระบบ https://share.streamlit.io/ และเชื่อมบัญชี GitHub
4. เลือก Create app / Deploy an app from GitHub เลือก repository และ branch ที่ใช้ กำหนด Main file path เป็น app.py
5. ใน Advanced settings เลือก Python 3.12 แล้ว Deploy
6. ตรวจการตั้งค่า sharing ให้ผู้ตรวจเปิดแอปได้ และทดสอบลิงก์จากหน้าต่างที่ไม่ได้เข้าสู่ระบบก่อนส่งงาน

หากใช้ repository สาธารณะ ข้อมูลและไฟล์ประกอบใน repository จะเปิดอ่านได้ด้วย ชุดนี้ไม่มีรหัสผ่านหรือ API key และตัวแอปไม่ต้องใช้ secrets

คู่มือทางการ: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## ขอบเขตและการตรวจสอบ

- 363 กลุ่ม / มีคิว 73 / ออกจากคิว 14 / เวลารอ strict ใช้ได้ 72 / เวลามื้ออาหารใช้ได้ 346
- Walkin ที่เวลามื้ออาหารใช้ได้ 198 กลุ่ม เกิน 120 นาที 21 กลุ่ม
- เฉพาะวันที่มีคิว 143 และ 153: Walkin ใช้ได้ 103 กลุ่ม เกิน 120 นาที 12 กลุ่ม เวลาส่วนเกินรวม 333 นาที-กลุ่ม และตรงกับช่วงมีคิว 246 นาที-กลุ่ม
- การจำกัดเวลาเป็นการตัดส่วนเกินเชิงสมมติฐาน ไม่ใช่แบบจำลองการจัดโต๊ะหรือการพยากรณ์เวลารอ
- การเพิ่มราคาเป็นแบบจำลองรายได้ตามจำนวนผู้จ่ายเงินที่ผู้ใช้สมมติ ไม่ใช่การประมาณอุปสงค์หรือกำไร
- กราฟคิวเป็นภาพจากบันทึกเดิม ไม่ใช่ผลนโยบายให้ Inhouse ได้โต๊ะก่อน
- ชื่อกลุ่ม In house / Walk in ใน CSV ต้นทางถูกแสดงเป็น Inhouse / Walkin ภายในแอปเพื่อให้อ่านสม่ำเสมอ ไม่มีการเปลี่ยนแปลงไฟล์อ้างอิง
- ทดสอบค่าคำนวณหลัก การเปิดทั้ง 5 หน้า ตัวควบคุมสถานการณ์ และกรณีไม่เลือกวันแล้ว
